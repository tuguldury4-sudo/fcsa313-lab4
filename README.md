Орчин — Eclipse Adoptium JDK 25.0.3, Apache Maven 3.9.9. [Хувилбарын бүрэн гаралт](results/versions.txt)

`mvn test` командаар 8 тестийн методыг ажиллуулсан. Үүнээс 2 нь parameterized бөгөөд тус бүр 10, 3 оролттой. Үлдсэн 6 энгийн тестийн хамт 19 гүйцэтгэлээс 19 тэнцсэн. [Үндсэн гаралт](results/mvn-test.txt)

Мутацид `ninetyIsA` ба `letterBoundaries`-ийн 90 онооны кейс A хүлээж B авсан. Нийт 2 тест унаж, Maven exit 1 буцаасан. `>= 90` нөхцөлийг сэргээж дахин ажиллуулахад exit 0 гарсан. [Мутацийн гаралт](results/mvn-test-mutant.txt)

`letterGrade` нь A–F ангиллын доод хязгаарууд болон 0–100 мужийг шалгана. Хамгийн мэдрэмтгий зааг нь 90 бөгөөд `>= 90`-ийг `> 90` болговол яг 90 оноо B ангилалд орно. `ninetyIsA` болон `letterBoundaries`-ийн 90-ийн мөр A хүлээдэг. `totalScore` нь бүрэлдэхүүн бүрийн хязгаарыг нэмж нийлбэрлэхээс өмнө шалгана. Бутархай онооны кейс нийлбэрийг бүхэл рүү тасалдаг өөрчлөлтийг илрүүлэх боломжтой. NaN болон хязгааргүй утгад exception шалгадаг тест нь бодит тооны энгийн хоёр талын харьцуулалт дангаараа хүрэлцэхгүйг харуулна.
